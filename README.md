# Teensy 3.6 USキーボード入力 → JIS配列出力 変換アダプタ

Teensy 3.6 の USB Host ポートに接続した **US（英語）配列キーボード** の入力を、OS側（Mac / Windows / Linux）が **JIS（日本語）配列設定** の環境において意図通りに入力できるようリアルタイム変換して送信するハードウェア・プロキシファームウェアです。

---

## 主な機能と特徴

1. **完全なハードウェア変換**
   - PC側に専用ドライバや常駐ソフトのインストールが不要。
   - 会社の管理PCなど、キーボード配列設定の変更や外部ソフトウェア導入が禁止されている環境でもそのまま利用可能。

2. **Shift修飾キーの動的コントロール**
   - US配列とJIS配列で異なるShift記号のペア（`@`, `^`, `&`, `*`, `(`, `)`, `_`, `+`, `{`, `}`, `|`, `:`, `"`, `~` など）を自動検知。
   - 送信時のみ動的にShiftを付加/解除し、打鍵した通りの文字を出力。

3. **日本語IMEの切り替え対応**
   - `Alt + ` `（バッククォート）の同時押しを検知し、日本語IMEの「全角/半角」切り替えキーとして透過。
   - 単体押し時はプログラミング等で多用される `` ` ``（バッククォート）や `~`（チルダ）が入力可能。

4. **Nキーロールオーバー（最大6キー同時押し）対応**
   - 複数キー同時押しや高速タイピング時も、各キーの変換状態を追跡して正常に処理。

5. **LED状態同期**
   - PC側の CapsLock / NumLock / ScrollLock LED 状態を受信し、USキーボード側のインジケータLEDへ即時反映。

## 実装上の技術的ポイント

1. **USB HID Usage Maximum の 255 拡張 (`src/usb_desc.c`)**
   - Teensyduino 標準の HID Report Descriptor では `Usage Maximum` / `Logical Maximum` が `0x7F`（127）に制限されており、JIS特有の拡張キー（`0x87`：ろ/アンダーバー、`0x89`：円記号/パイプ等）がOS側で破棄される不具合がありました。
   - 本プロジェクトでは `usb_desc.c` をオーバーライドし、上限を `0xFF`（255）へ拡張することで、これら拡張キーコードの正常送出を実現しています。

2. **Raw HID コールバックによる完全なスキャンコード制御**
   - `USBHost_t36` の `attachRawPress` / `attachRawRelease` を採用し、修飾キー（103〜110）および通常キー（4〜115）を生のHIDコード単位でキャプチャして動的マッピングを行っています。

3. **プラグ＆プレイ即時起動**
   - シリアル通信接続待ち（`while (!Serial);`）を排除し、PC接続後即座にキーボードとして動作します。

## ビルドおよび書き込み手順

### 必要環境
- macOS
- `arm-none-eabi-gcc`（Teensyduino内蔵またはシステムツールチェーン）
- `teensy_loader_cli`

### ビルド
```bash
make clean && make
```
`build/us2jpk.hex` が生成されます。

### 書き込み
```bash
make flash
# または
teensy_loader_cli --mcu=TEENSY36 -v -w build/us2jpk.hex
```
実行後、Teensy 3.6 本体のプッシュボタンを 1 回押すと書き込みが完了します。
